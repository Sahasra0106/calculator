# Calculator

## About the Project
This is a simple and user-friendly Calculator application developed using HTML, CSS, and JavaScript. It performs basic arithmetic operations with a clean and simple interface.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Clear button to reset calculations
- Simple and user-friendly interface
- Responsive design

## Technologies Used
- **HTML5** – Structure of the calculator
- **CSS3** – Styling and layout
- **JavaScript** – Calculator functionality and operations

## Project Structure
```text
Calculator/
│
├── index.html
├── style.css
└── script.js
```

## How to Run
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Start performing calculations.
